# フォックスの挑戦・クイズ検索ツール

iPhone Safariでの利用を想定した静的Webアプリです。サーバー、データベース、外部APIは使用しません。

## ファイル構成
- `index.html`：検索・練習・データ管理画面
- `style.css`：画面デザイン
- `script.js`：検索・端末内保存・JSON入出力
- `help.html`：使い方
- `data/questions.json`：初期問題データ

## 主な機能
- 1文字からの即時検索
- 問題文の先頭一致を優先した候補表示
- 全角／半角、ひらがな／カタカナなどを正規化した検索
- 答えの表示とコピー
- ランダム出題
- 個人問題の追加・編集・削除
- 個人追加分のJSON書き出し・読み込み

## データの扱い
- 初期問題は `data/questions.json` から読み込みます。
- 個人で追加した問題は端末のブラウザ内（localStorage）に保存されます。
- JSON書き出しの対象は個人追加分のみです。
- JSON読み込み時は問題文を正規化して重複判定し、重複はスキップします。
- JSONの項目は `id`、`question`、`answer`、`reading` です。`reading` は任意です。
- 旧バージョンのlocalStorageデータも読み込み時に不要項目を除去して新形式へ移行します。

## 初期データについて
初期データは掲載問題を網羅しているものではなく、問題文・回答の正確性を保証するものでもありません。利用時には必要に応じて内容を確認してください。

## JSON形式
```json
{
  "schemaVersion": 1,
  "questions": [
    {
      "id": "unique-id",
      "question": "問題文",
      "answer": "答え",
      "reading": "もんだいぶんのよみ"
    }
  ]
}
```

## ローカルでの利用
ZIPを展開し、フォルダ内のファイル一式を同じ構成のまま配置してください。`data`フォルダを含めてください。ブラウザで `index.html` を開く場合、ブラウザのセキュリティ制限によりJSONの読み込みが動作しないことがあります。その場合は、静的ファイルを配信できる環境で開いてください。
